Layanan backend yang mengekspos endpoint chat sederhana dan meneruskan percakapan ke Gemini API, lalu mengembalikan respons yang sudah dirapikan ke client.

## Fitur utama

- Endpoint tunggal untuk mengirim dan menerima pesan.
- Pemrosesan dasar konteks percakapan di sisi backend.

## Tech stack

- Node.js / Express sebagai backend.
- Integrasi Gemini API via HTTP client.

## Project overview

Warung Daeng adalah aplikasi SaaS untuk memodernisasi operasional warung kecil-menengah — dari pencatatan stok, manajemen kasbon, hingga laporan laba yang otomatis terhitung, menggantikan buku catatan manual.

- Landing page dengan penjelasan fitur, solusi, dan skema harga, plus opsi coba gratis.
- Dashboard ringkas: total pendapatan, jumlah transaksi, total produk, dan pelanggan aktif — masing-masing dengan indikator naik/turun dibanding periode sebelumnya.
- Grafik pendapatan harian dan daftar transaksi terakhir langsung dari halaman utama.
- Halaman Transaksi bergaya kasir POS: cari produk/SKU, filter kategori, keranjang pesanan, dan total tagihan real-time.
- Model bisnis freemium — ada badge "Dapatkan Akses PRO" dan menu Langganan untuk upgrade paket.

## Fitur utama

- **Dashboard** — pendapatan, transaksi, stok produk, dan pelanggan aktif dalam satu layar.
- **Produk & Transaksi** — pencatatan stok dan pencatatan penjualan gaya kasir modern.
- **Laporan** — laba rugi tercatat otomatis, tanpa hitung manual.
- **Pelanggan** — data pelanggan tersimpan untuk histori dan analisis sederhana.
- **Langganan** — paket Pro untuk fitur lanjutan.

## Tech stack

- Vue.js (frontend)
- Go (backend)
- MySQL (database)
- Docker (containerization)
- Postman (API testing/documentation)

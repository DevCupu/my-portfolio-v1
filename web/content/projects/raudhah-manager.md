## Overview

Dashboard operasional untuk travel umrah dan haji yang membantu tim mengelola data jemaah, membagi tugas operator, dan memantau proses QR Code Raudhah dalam satu tempat.

## What It Solves

Mengurangi input manual dan koordinasi yang tersebar saat mengelola banyak jemaah. Admin dapat melihat prioritas dan progres tim, sementara operator hanya mengerjakan jemaah yang ditugaskan.

## Key Features

- **AI visa extraction:** membaca data nama, paspor, visa, gender, dan travel dari PDF atau gambar menggunakan Gemini AI.
- **Operator assignment:** membagi antrean jemaah kepada operator dengan akses kerja masing-masing.
- **Live dashboard:** memantau status QR, progres operator, dan aktivitas operasional secara real-time.
- **Departure priority:** menandai jemaah yang perlu diproses lebih dulu berdasarkan jadwal keluar dari Madinah.
- **Excel workflow:** impor dan ekspor data jemaah untuk mempercepat input serta pelaporan.
- **Flexible data fields:** menambahkan informasi seperti bus, hotel, atau mutawwif tanpa mengubah struktur utama.

## My Contribution

Mengembangkan dashboard operasional, alur admin dan operator, manajemen data jemaah, sinkronisasi real-time dengan Supabase, serta integrasi Gemini AI untuk ekstraksi data visa.

## Tech Stack

React 19, TypeScript, Vite, Tailwind CSS, Supabase, Google Gemini API, pdfjs-dist, SheetJS, Lucide Icons, dan Motion.

## Workflow

Admin mengimpor data atau memindai visa dengan AI, membagikan jemaah kepada operator, lalu memantau pembaruan status dan dokumentasi QR dari dashboard real-time.
